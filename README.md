# Log Analyzer

Offline browser tool for analyzing log files

## Supported formats

- Text logs: `2026-01-19 10:30:45 [INFO] service — message`  
- JSON logs: JSON Lines (one object per line) or JSON array

## How to use

1. Open `index.html` in a browser  
2. Select a `.log` or `.json` file  
3. Filter by level, time range, or keyword  
4. Export results to CSV
