# Js Log Parser

Простое веб-приложение парсинга логов

---

## Функционал

- Загрузка логов из текстового файла нужного формата или .json-файла;
- Фильтрация по уровню, дате, ключевому слову в сообщении;
- Экспорт отфильтрованных логов в CSV;
- Поддержка работы оффлайн.

---

## Что использовано

- **HTML5**
- **CSS3**
- **JavaScript**
